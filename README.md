# MouseTuner Homebrew tap

```sh
brew install --cask mousetuner/tap/mousetuner
```

MouseTuner is a menu bar app that gives any mouse on macOS smooth scrolling, button
mapping, and Logitech HID++ hardware control. See https://mousetuner.com.

The cask here is generated by the release pipeline from the notarized build, so its
checksum always matches the package published on the release page.
